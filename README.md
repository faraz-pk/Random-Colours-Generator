# 🌈 Random Colours Generator

A simple and interactive Random Colours Generator built using HTML, CSS, and JavaScript.
This application generates random colors and displays their color codes dynamically.

---

## 📌 Features

* Generate random colors instantly
* Display HEX/RGB color codes
* Interactive user interface
* Responsive design
* Simple and lightweight application
* Easy to use

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
